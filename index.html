個人郵件保存工具

讓自己的郵件紀錄留在自己的電腦。

Local Gmail Archive 透過 Gmail 唯讀授權，協助擁有者在 Mac 上保存及整理自己授權的郵件。

目前進度

目前已完成有限的 Gmail API 背景讀取試驗。近一個月的全量匯入、完整新增郵件驗收、附件全文搜尋與 Obsidian 整合仍在建置中。

郵件由本機程式直接向 Gmail API 讀取，不需 AI 服務即可收信。雲端 AI 郵件整理目前尚未啟用。

只讀取本人授權的信箱

本工具只請求 Gmail 唯讀權限。它不會透過這項授權寄送、移動或刪除郵件；程式附件也不會執行。

資料處理方式

已擷取的郵件快照與同步資料保存在擁有者的 Mac。網站只提供產品與資料處理說明，不承載信件或附件。詳情請閱讀隱私權說明。
